# Implementation Plan

> 本計画は `requirements.md`（要件1〜13 / 受入基準110件）と `design.md` に基づく。
>
> **タスク1〜8 は実機を必要としない。** 継ぎ目・真値・実測算出・帰属・判断・出力は、
> 上流3パッケージの**公開型の形**にしか依存しないため、公開型を模した最小ダブルと
> 合成した軌道だけで完成まで到達できる。
>
> **タスク9 はハードウェア必須**であり、Raspberry Pi 4 と RealSense D435 が揃い、
> かつ `sensing-foundation` / `flying-object-tracking` / `world-frame-calibration` の
> **実装が完了するまで着手できない**。この分割は「実機待ちの期間に何も進まない」事態を避けるための意図的なものである。
>
> ⚠️ **本 Spec が触るファイルは `src/m1_validation/**`、`tests/m1_validation/**`、自 Spec ディレクトリ、
> ルート `pyproject.toml` への追記、および `docs/requirements.md §3` だけである。**
> 上流3 Spec が並行して同じ `pyproject.toml` を追記するため、既存行を書き換えず追記のみを行う。
>
> ⚠️ **`docs/requirements.md §3` の更新（タスク9.7）は、M1 実測値が揃っていることをゲートとする。**
> 想定のまま書き換えない。

    予約段階名を渡すと拒否され、ログ器の取り出し入口が同一の実体を返すことをテストで固定する

- [ ] 2.2 継ぎ目（カメラ座標系 → 予測入力）を実装する ★
  - カメラ座標系の点列とキャリブレーション結果から、World 座標系のサンプル列と由来情報列を生成する
  - **座標変換は上流の変換を呼ぶだけ**とし、変換式を再実装しない
  - **時刻をそのまま引き継ぐ**（再基準化しない）。**単位変換を挟まない**
  - 座標系がカメラ座標系でない場合、および受け渡し形式版が未知の場合に、識別可能な理由で失敗させる
  - 欠測・床面下・観測品質下限未満の点を除外し、**除外理由ごとの件数を必ず返す**（静かに捨てない）
  - World 系で表したカメラ視線方向を各サンプルについて算出する
  - **サンプルへ品質情報を入れない**（予測入力の契約は4項目のまま）旨と、
    カメラ固有の型・画素座標・カメラパラメータを出力側へ出さない旨を docstring に明記する
  - 検出・追跡パッケージへの入口を**本モジュールに2つだけ**設ける:

    (b) 追跡パイプラインを生成して返す入口。後者は**本 Spec が生成できない2つの値**

  - **本 Spec は追跡の設定値も方式も決めない**（既定値を持たない）。
    (a) が存在するのは、検出・追跡パッケージを import するのが本モジュールだけという境界を保ったまま、
    入口層が上流の解決結果を手に入れられるようにするためだけである旨を docstring に明記する
  - 観測可能な完了状態: 既知の姿勢で合成した点列を変換すると既知の World 座標と一致し、
    時刻が入力と同一値で、サンプル列と由来情報列の長さが一致する。
    追跡設定の素通し入口が上流の解決結果をそのまま返し、
    パイプライン生成入口が受け取った2値を改変せずに渡すことをダブルで固定する

  - _Depends: 1.3_
  - _Boundary: Seam_

  - キャリブレーション結果を読み、形式版の既知性・ストリーム設定と内部パラメータの一致を検査する
  - **検証を通過していない結果での実行を既定で拒否**し、明示的な許可でのみ続行できるようにする
  - 許可して続行した場合、**生成物すべてに未検証の印を伝播させる**

  - 観測可能な完了状態: 検証状態の4値それぞれに対して拒否・許可・印の付き方が期待どおりになり、

  - 同一の内部パラメータ・画素座標・生の奥行き値を、**検出・追跡側の逆投影経路**と
    **座標変換（キャリブレーション）側の逆投影経路**の両方へ通し、
    **結果が完全に一致する**ことを確かめる（浮動小数の厳密比較。**許容差を置かない**）
  - 無効な生の奥行き値、および境界値（無効値そのもの、画素中心規約が効く半画素ずれ、
    奥行きスケールの適用位置が効く値）を含めて比較する
  - **なぜここでしか検証できないのか**を docstring に書く: 上流2 Spec は**同一の逆投影の基本演算**
    （上流基盤 Spec が所有）に乗る前提であり、**両方を import する正当な理由を持つのは本 Spec だけ**である
  - **ずれた場合の症状**を docstring に書く: ずれは投擲群に共通する偏りとして現れ、

    境界規則を本テストで緩めない
  - ⚠️ **前提**: 逆投影の基本演算の一元化（上流基盤 Spec が所有し、上流2 Spec が独自実装を捨てて

  - 観測可能な完了状態: 契約テストが単独で実行でき、片方の経路の値を意図的にずらすと失敗する

## 3. 1投擲の実行と記録

- [ ] 3. 1投擲の実行と記録

- [ ] 3.1 1投擲の実行と Throw Record への記録を実装する
  - 取得 → 検出・追跡 → 継ぎ目 → 逐次予測 → 記録という順序で1投擲を実行する
  - **追跡パイプラインは継ぎ目モジュールの生成入口から得る**（本モジュールは検出・追跡パッケージを
    import しない）。生成に要る上流の追跡設定とログ器は**呼び出し元から不透明値として受け取り、
    解釈せずに素通しする**（型注釈も具体型にせず、上流パッケージを import しない制約を型の上でも守る）
  - **検証ゲートを投擲を始める前に評価する**（走らせてから拒否しない）
  - 新しいサンプルが追加されるたびに予測を更新し、予測系列として保持する（予測の再計算は予測コアに委ねる）
  - 記録は予測コアの Throw Record スキーマをそのまま使い、**再定義しない**
  - 本 Spec 固有の情報（レイアウト要約・キャリブレーション要約・追跡の識別情報・由来情報・除外件数・
    検証済みか）を**拡張領域へ退避**し、上流が使う拡張キーを上書きしない
  - ⚠️ **予測コアの記録生成メソッドは拡張領域を引数に取らない**（記録の値オブジェクトは
    frozen かつ slots である）。拡張領域の付与は
    **`dataclasses.replace(record, extra={...})`**、または蓄積済みのサンプル列・予測系列からの
    **公開コンストラクタでの直接構築**のいずれかで行う。
    **`trajectory-simulator` は後者を採っており、両下流が同じ手段を採ること**を意図している。
    **予測コアには一切手を入れない**（迂回であって修正ではない）
  - 予測ごとに予測区間の計測を送出する。送出は完了を待たず、**予測経路の中で集計しない**
  - 入力元の種別を記録に残す
  - 観測可能な完了状態: 合成入力に対して1投擲が通り、記録を読み戻すと予測系列と由来情報が復元される
  - _Requirements: 2.3, 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 7.4_
  - _Depends: 2.1, 2.3_
  - _Boundary: ThrowRunner_

- [ ] 3.2 失敗投擲の扱いと再実行の一致を固定する
  - 有効サンプルが0件、または追跡が成立しなかった投擲を、**理由付きで記録**する
  - 失敗投擲が成功試行の集計から除外されることを固定する
  - 上流の失敗を投擲単位で捕捉し、次の投擲へ進めるようにする
  - 同一の記録済み入力に対する再実行が、同一の予測系列と同一の記録内容を返すことを固定する
  - 観測可能な完了状態: 検出が1点も出ない入力で失敗理由付きの記録が残り、
    同一入力の2回実行が同一内容の記録を生成する
  - _Requirements: 3.7, 3.8_
  - _Depends: 3.1_
  - _Boundary: ThrowRunner_

## 4. 真値と実測7項目

- [ ] 4. 真値と実測7項目

- [ ] 4.1 真値の受け取りと導出を実装する
  - 実際の落下地点を外部ファイルから受け取り、**測り方の記述を必須**とする
  - 実際の落下時刻を、観測サンプル列が床面高さを**跨ぐ隣接2点の内挿**として求め、
    跨ぐ区間が無ければ欠測として扱う
  - リリース時刻を、推定軌道を観測開始より前へ**外挿**し、レイアウトのリリース高さに達する時刻として求める
  - 各真値に**求め方の種別と不確かさの目安**を併記する。外挿の不確かさは外挿区間の長さと残差から導く
  - 外部の合図が記録されている場合、外挿値との差を残す
  - 真値の入力を投擲の実行と分離し、**実行後に追記できる**ようにする
  - 記録に存在しない識別子の真値は警告として報告し、黙って捨てない
  - **求め方を書かずに数値だけを出すと誤差の出どころを議論できない**旨を docstring に明記する
  - 観測可能な完了状態: 既知の軌道から生成した記録に対し、内挿による落下時刻と外挿によるリリース時刻が
    解析解と一致し、跨ぐ区間が無い入力では欠測が返る
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5, 4.6, 4.7_
  - _Depends: 1.4, 3.1_
  - _Boundary: TruthDeriver_

- [ ] 4.2 (P) 実測項目 1 / 2 / 6 を算出する
  - 総飛行時間を「実際の落下時刻 − リリース時刻」として算出する
  - **リリースから検出開始までの時間**を「最初の有効サンプルの観測時刻 − リリース時刻」として算出する
  - 狙い誤差を「待機位置 → 実際の落下地点の水平距離」として算出する
  - 真値の不確かさを結果へ伝播させ、求め方の種別を結果に含める
