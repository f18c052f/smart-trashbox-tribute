# ブリングアップ記録（teleop-bringup）

> [`bringup-procedure.md`](./bringup-procedure.md) の各段を実施した結果をここへ残す。
>
> ⚠️ **追記であり、上書きしない。** 再実施したときは新しい節を足す。
> ⚠️ **合格条件を満たさなかった段があれば、次の段へ進まない**（要件 10.8）。
> 不合格も記録として残す。何が起きなかったかではなく、**何が起きたか**を書く。

## 書き方

各段につき次を残す。

| 項目 | 補足 |
|---|---|
| 実施日 | |
| ファームウェアのコミットハッシュ | ⚠️ どの版で確認したかが特定できないと記録の意味が無い。`[env:bench]` / `[env:teleop]` の別も書く |
| 電源と設定 | 電圧・電流制限。安定化電源か LiPo か |
| 合否 | 合格条件それぞれについて ✅ / ❌ |
| 実測値 | 数値は丸めずそのまま |
| 不合格の内容と是正 | 何をどう直したか |
