model: claude-sonnet-5
---

現在の変更を確認し、コミットしてプッシュしてください。

手順:
1. `git status` と `git diff` （必要なら `git diff --cached` も）で変更内容を確認する。
2. コミットすべきファイルを `git add` でステージする（意図しないファイルは含めない）。
3. `CLAUDE.md` の方針に従い、**日本語**でコミットメッセージを書いて commit する。
4. 現在のブランチを `git push`（未追跡なら `-u origin <現在のブランチ>`）でリモートへ push する。
   このコマンドが呼ばれた時点で push の承認は得られているものとして、確認は挟まず実行してよい。
5. 最後に `git log --oneline -1` と `git status` で結果を短く報告する。

コミットすべき変更がなければ、その旨を報告して終了する（空コミットは作らない）。
